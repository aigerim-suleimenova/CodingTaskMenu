# CodingTaskMenu


### Application requirements
- PHP 7.4 or higher
- MySQL 5.7 or higher
- Apache/Nginx web server
- WordPress

- Located in `wordpress/wp-content/themes/custom-theme/`

# Installation
- git clone https://github.com/aigerim-suleimenova/CodingTaskMenu.git
- cd CodingTaskMenu
- Set up your local web server to point to the `wordpress` directory
- Create a MySQL database for the project
- Configure WordPress:
- Activate the "Custom Theme" from WordPress Admin → Appearance → Themes
- Install and activate the WooCommerce plugin
